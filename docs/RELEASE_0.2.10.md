# 0.2.10 · 数据自动刷新修复

星图与个股使用数据事件触发更新，并保留定时读取兜底。固定在详情中的股票、列表之外的股票也会更新，刷新保留周期、缩放与资料标签。报价、历史读取和后台操作分别排队，重复后台读取合并，结果到达后立即唤醒桌面。

K 线更新只读取当前日/周/月周期的尾部，替换该周期并保留更早历史；六条日均线仍基于完整日线预热。原生星图复用几何及文字缓存，浏览器星图复用静态画布并合并浮动提示更新，行情提交后失效，加载过程保留有效画布。历史总数缓存不影响最新报价时间。

实时源状态区分未配置、关闭、非交易时段、权限不足、限流、故障和成功。配置 Token 不代表具有 `rt_k` 权限；实际账号诊断返回过权限不足，需要单独开通 A 股实时日线接口。历史同步成功不会再被误认为实时采集成功。

验证：141 项常规 Rust 测试、40 项 Web 测试、严格 Clippy 通过；6000 股连续 8 轮原子更新通过，170 次读取保持一致。原生 6000 股绘制准备与细分验证见 [架构审查](REFRESH_ARCHITECTURE_AUDIT_2026-10-28.md)。夜间测试不能替代交易时段实盘验收。

继续使用 schema 6。发布包不包含配置凭据和数据库。关闭旧程序并备份配置、数据库后使用新版本；当前根目录运行程序和用户数据未替换。
