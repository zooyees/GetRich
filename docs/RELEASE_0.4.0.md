# 0.4.0 · 专业研究工作台

新增“专业工作台”入口，桌面与浏览器共用 Rust 数据、计算与账本，覆盖数据质量、指标分析、研究管理、本地预警、组合复盘和单证券策略验证。短线、波段、长线原有研究工作区继续保留。

- 数据：日线修订与资料版本、独立来源报价核对、官方日历缺口报告、复权因子/约束/公司行为补齐、授权 CSV 原子导入。成功数据落盘，重复资料跳过；原始数据与来源、可得/观测时钟分别保存。
- 图表：主 K 线原始/前复权/后复权切换，日周月及保存的研究证据使用相同口径；均线全历史预热。专业工作台增加日线/分钟 MACD 柱、RSI、ATR 副图、多股共同日期强弱比较、同行财务、估值情景和公告事件轴。分钟使用已落盘的实际 OHLC，已知日内缺口后重新预热，不用日线填补。
- 研究：命名筛选规则、研究池、标签、研究模板、分析/策略参数保存与历史版本恢复；跨股票检索笔记，载入模板保护未保存草稿。
- 预警：价格、前20日相对量能及公告关键词；后台评估、陈旧报价隔离、条件边沿和版本去重、冷却、待阅数量及确认。
- 组合：真实成交、入出金、费用、分红、送股流水；重复流水校验、整批对账、作废/恢复审计；现金、成本、已实现/未实现收益、持仓贡献、行业集中度、单位净值与回撤。缺价保持未知，币种分账。
- 回测：单证券均线策略，上一日信号/下一开盘执行，交易单位、停牌、涨跌停、T+1、容量、佣金、税费、滑点、登记与派息；样本外区间、成本扰动、成交和跳过原因。冻结输入与参数，可导出和重放。
- 严格时点模式默认启用：需授权时点日线档案、上市/退市历史，以及决策前可得的日历、约束、因子和公司行为。不足则保存缺口，不生成收益。关闭后明确标记为历史研究模拟。来源声明的历史可得时间与本地实际导入时间分别保留。

操作方法和 CSV 列定义见 `PROFESSIONAL_WORKBENCH_GUIDE.md`，与原方案对应的实现清单见 `PROFESSIONAL_WORKSTATION_PLAN_2026-11-01.md`。

数据库升级到 schema 10，旧研究记录与数据保留；日线首次纳入版本管理使用真实升级时间，不伪造历史观测时间。日内 rt_k 修订和独立报价按分钟采样保留审计，规范行情表仍保存每次有效更新；历史正式修订逐次留存。独立报价采样保留7天、分批清理，避免无限增大数据库。

升级需关闭旧程序，先备份配置和数据库；降级须恢复旧数据库快照。发布包不包含 Token、个人配置、笔记或数据库。实时数据质量取决于已授权来源：日线权限不等于实时、分钟或盘口权限。本版不提供券商下单或未授权盘口。

回测是单证券、日线成交模型。日线不能还原开盘盘口、排队及逐笔成交；成交容量含当日总量事后可行性约束，费用由用户提供。严格模式验证输入的声明时钟，不核证供应商声明的真实性，不代表无幸存者偏差的全市场选股回测或策略有效性。
