# GetRich 0.2.1 开发与验收说明

0.2.1 针对用户截图继续修正桌面布局；本次具体改动和验收记录见 [桌面 UI 修正说明](UI_CORRECTIONS_0.2.1.md)。

日期：2026-10-25；对应评估：`PRODUCT_AUDIT_2026-10-24.md`。

本轮针对评估中的 36 项问题改造核心数据服务、Windows 桌面和 Web 工作站。原评估文档保留，下面区分已开发内容与实际验证边界。正式用户数据库及原发布目录未用于故障注入。

## 本轮 UI 与星图重设计

根据新增反馈，重新设计桌面与 Web 的导航、行情、个股详情、数据中心和设置，并把市场态势主视图改为行业大盘星图。支持同日市值 / 成交额 / 等面积、行业下钻、搜索、自选高亮、缩放平移及个股来源速览。完整评估、实现和数据边界见 [界面与星图落地说明](UI_MARKET_ATLAS_2026-10-25.md)。

## 数据与交互约定

- 行情优先使用统一投影中的报价；后续日线代表更晚的交易日时提升报价。同日实时与日线的写入优先级保留兼容规则，当前并未接入逐笔交易所修订号。
- 周/月线以已导入日线为基础合成。“当前周期”只表示仍处于本周/本月，不保证每个交易日都已导入。
- 预览不落库；应用时再次校验输入指纹。应用前其他任务可能改变数据库，最终写入计数以任务结果为准。
- 排队和下载阶段可取消；原子写入阶段不接受取消，事务完成后可查询结果。取消不会回滚此前已提交批次。
- Tushare 连接测试验证交易日历权限；行情与历史权限由对应同步任务分别报告。
- A 股日历未知时标注 fallback；港美股当前没有远程交易日历来源，不宣称其节假日状态。
- 美股盘中输入要求带偏移的 RFC3339。桌面纽约时区使用 2007 年起现行夏令时规则；更早盘中记录保留 UTC，避免推测历史偏移。规则依据：[NIST 夏令时说明](https://www.nist.gov/pml/time-and-frequency-division/popular-links/daylight-saving-time-dst)。Web 使用浏览器 Intl 时区库。
- 全部市场结论均标注样本范围。资金流、新闻及账号未授权的数据不生成虚构结果。

## 验证

自动回归命令：

```powershell
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
node --experimental-vm-modules --test tests/web/*.test.cjs
cargo build --workspace
node tests/api/workstation.cjs
```

本地核心/跨功能/图表/API/桌面布局单元回归 106 项、Web 脚本回归 14 项、进程级验收 8 个场景。进程验收包括 6001 标的分页及星图展示无重复遗漏、缺失市值不替换口径、双进程设置合并、64 个事件连接后健康及普通查询仍可用、预览不落库、任务最终结果和快照版本。

重设计前的 Windows 原生烟测使用隔离目录：空库 → 预览 300 条 → 后台应用 → 标的 6/报价 6/K 线 288 → 任务完成；检查列表与详情价、图表坐标及底部摘要，并实际切换、放大短月线，窗口保持响应。

0.2.1 桌面额外运行深浅主题、四种窗口尺寸布局检查，覆盖四个设置分类、导入预览、空库、详情与星图。已在独立数据库上完成普通与最大化窗口的实际界面检查和演示数据导入流程，详见 UI_CORRECTIONS_0.2.1.md。

Web 回归使用真实脚本模块和最小 DOM 模型，不等同于真实浏览器端到端覆盖。真实账号权限、交易时段吞吐、长期故障压测、390/768/1024/1440 浏览器截图矩阵、多显示器 DPI 与完整读屏矩阵仍需在对应环境验收；未把这些写成已通过。

## 升级与运行

0.2.0 使用 schema 5，首次运行自动迁移，增加统一报价视图、隔离记录、任务、账号预算和快照版本。迁移与写入使用 SQLite 事务。升级前备份旧目录中的数据库和 config.json，关闭旧程序后复制到新目录。

压缩包不包含用户数据库、Token 或验收产生的数据库；演示 JSON 作为未导入的示例文件提供。自选、数据源、外观均从“设置”管理；演示数据通过“数据中心 → 使用演示文件 → 校验预览 → 应用有效记录”导入。

启动 GetRich.exe 使用桌面与内嵌本地服务；GetRich-CLI.exe serve 可独立提供 Web 工作站。端口占用时按启动提示关闭占用实例或更改绑定，先核对设置页的数据目录再连接浏览器。
