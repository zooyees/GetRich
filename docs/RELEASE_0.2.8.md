# GetRich 0.2.8 · 行情侧栏与 K 线工具栏布局修正

- 左侧市场范围、涨跌筛选采用等宽双列，标签、输入框顶边与高度统一；标题、筛选、表格及分页使用同一组左右边界。代码和名称表头靠左，数值表头与数据靠右，保持侧栏占窗口宽度 20%。
- 行情刷新提示改为标题行的固定尺寸进度标记，保留列表位置，避免后台刷新时组件上下跳动。
- K 线工具栏重新分组：周期切换为独立分段控件，日期范围与当前开高低收集中显示，右侧导航和历史更新采用统一高度与间距。窄屏在同一个工具栏内换行。
- 六条日均线使用独立紧凑控件，名称与数值保持在同一组内；宽屏六列，普通窗口三列，小窗口两列或一列。保留 MA5/10/20/30/120/250、数值跟随光标及 checkbox 设置保存。
- 桌面和浏览器同步调整。历史加载、均线计算、缩放逻辑和数据源权限保持原有行为；本版使用 schema 6，无新增迁移。
- 验证：11 项桌面回归、32 项 Web 回归及严格 Clippy 检查通过；独立浏览器核对 1024/1440/1920 像素宽度，筛选框等宽对齐、均线名称与数值不重叠。使用独立数据库实机核对普通及最大化窗口、市场下拉切换和全市场列表分页。

升级前关闭旧版本，保留现有 config.json 和数据库。发布压缩包不包含用户数据库、个人凭据或测试配置。
