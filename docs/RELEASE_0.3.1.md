# 0.3.1 · 三种研究工作区

用户已确认盘中短线、日线波段、基本面长线都需要。本版在0.3.0研究底座上落实三种工作区，两端共用计算和存储。入口：行情 → 个股详情 → 研究分析。系统性路线与后续验收见[建设方案](PROFESSIONAL_WORKSTATION_PLAN_2026-11-01.md)。

- 盘中短线：有效分钟序列、样本均价及偏离、连续15交易分钟收益、样本高低、量额。过滤未来数据、错误时间坐标，报告缺口及数据时效，缺分钟不使用日线替代。
- 日线波段：延续本地收益、均线、RSI/MACD/ATR、波动和回撤分析，保留原始价格/未复权提示及计算口径。
- 基本面长线：估值、ROE、增长、利润率、负债、经营现金流及现金收益比。按截止日过滤公告，分别显示报告期、公告日、估值日和来源获取时间。
- 每只股票在三种工作区有独立的四段研究模板、草稿、版本和保存时证据快照。最近选择写入偏好；快速切换、旧请求返回和后台读取不覆盖当前草稿。
- 活跃研究页复用后台分钟/历史/F10任务，30秒检查本地状态，遵守原有缓存和失败退避；支持手动更新，重复执行中的任务合并。重算本地分析不下载数据。

本版包含0.3.0的条件选股、版本历史及数据库备份。分钟/F10实时能力受数据源授权和服务可用性约束，不能以频繁刷新绕过。港美股仍支持已导入日线的本地分析，当前资料源以A股为范围。

数据库 schema 9：旧研究记录归入“日线波段”，历史版本和证据保持不变。升级前关闭旧程序并备份数据库与配置；降级恢复旧备份。发布包不含个人配置、数据库和Token，也不自动覆盖根目录运行程序。

仍待后续建设：复权及修订版本、多源对照、指标副图、预警、组合归因和可信回测。财务缓存可能为后续修订值，不据此宣称具备完整点时数据；本版不提供自动交易。
