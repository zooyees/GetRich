# 专业工作台操作手册 · 0.4.0

## 从哪里开始

顶部“专业工作台”按概览、数据、分析、研究、预警、组合、回测组织。先选分类和工具，填写参数后执行。表单按工具保留草稿；服务器读写和计算在后台执行。结果支持表格、行详情、打开个股、导出 CSV 与完整 JSON（含口径和输入上下文）。桌面对应复制到剪贴板，浏览器下载文件。

行情 → 个股仍提供分时/日周月 K、F10、资金和公告。研究分析中的短线、波段、长线分别保留笔记版本；模板只载入草稿，保存才落盘，不覆盖当前未保存内容。

## 数据准备与复权

1. 设置已授权 Tushare 连接；数据中心补齐股票、行情与市值。在专业工作台“补齐专业数据”下载指定股票及区间的复权因子、交易日历、涨跌停价和公司行为原始证据。
2. 供应商拒绝或无权限时保留旧资料，并在结果中列出具体接口错误。分红原始接口的税前金额不自动转换成个人税后现金；涨跌停价不等于完整停牌、交易单位和公司行为核验。
3. “数据质量检查”检查日期、OHLC、负量额、日历缺口和因子覆盖。没有正式日历时不猜测周一至周五都是交易日；缺日线仍需区分停牌与漏采。
4. 主 K 线和专业图表选择不复权/前复权/后复权。前复权锚定截止日之前最新因子，后复权锚定区间历史最早因子；逐根因子缺失或来源混杂时阻止计算。均线与研究证据随价格口径一起变化，成交量/金额保持原口径。
5. 同一数据集存在多个来源时填写来源名称；“多源报价核对”只比较同币种及指定时间差内的报价。只有一个来源时，无法独立证明价格准确。

原有服务器成功响应缓存、历史区间覆盖与缺口下载继续工作。实时数据会变化，不能把一次已落盘当作永远不必更新；“跳过重复”适用于相同资料内容或已覆盖的历史区间，手动历史更新用于处理供应商修订。Tushare 日历缺日补齐按年度大小分块，因子补齐扩展到本地首根日线以满足预热。

## 授权 CSV 导入

数据 → 导入专业资料 → 选择资料类型及来源。复制界面显示的表头，粘贴或选择 UTF-8 CSV。每批最多4MB、10,000行；含引号、逗号和换行的字段使用标准双引号转义。整批验证后事务入库，任一错误整批回滚。相同来源相同最新内容不重复入库；A→B→A仍记录恢复版本。

日期用 `YYYY-MM-DD`。`known_at` 可选时留空表示没有历史发布时间，不能用猜测值补齐；严格时点资料须填写真实来源可得时间，格式如 `2024-01-03T15:05:00+08:00`。本地导入时间由程序单独记录。数值单位须与主库一致：价格为计价币种/股，成交量为股，成交额为该币种元；百分比字段按百分点输入。

| 类型 | 必需/主要列 | 说明 |
| --- | --- | --- |
| factors | symbol,market,date,factor,known_at | factor>0；known_at用于时点核验 |
| calendar | date,exchange,is_open,known_at | 交易所SSE/SZSE/BSE/HKEX/US；is_open为0/1，包含休市日 |
| observations | symbol,market,timestamp,last,volume,turnover,currency | 独立报价；timestamp带时区，币种与市场一致 |
| constraints | symbol,market,date,up_limit,down_limit,suspended,lot_size,min_buy,t_plus_one,actions_checked,no_limit,known_at | 布尔值明确0/1；lot_size为递增单位，min_buy为最低买入量；无价格限制两价留空且no_limit=1；actions_checked=1仅在已核验当天公司行为时填写 |
| actions | symbol,market,date,record_date,pay_date,cash_per_share,share_ratio,known_at | date为除权日；现金为实际每股净现金；share_ratio为行为后/前股数 |
| financial | symbol,market,end_date,ann_date,eps,ocfps,roe,or_yoy,netprofit_yoy,debt_to_assets,grossprofit_margin,netprofit_margin | 报告期与公告日分列；数值空白表示未知 |
| valuation | symbol,market,date,pe_ttm,pb,dv_ttm | 日估值版本，避免与财报期混淆 |
| bar_history | symbol,market,date,known_at,open,high,low,close,volume,turnover | 沪深京完整日线档案；可得时间不得早于当日15:00；后续修订用其真实可得时间另存 |
| security_history | symbol,market,date,known_at,status,list_date,delist_date | date为生效日；status为listed/delisted；尚无退市日留空，支持已退市证券的历史研究 |

`market` 使用 CN.SH / CN.SZ / CN.BJ / HK / US，证券代码须先导入股票列表。CSV 未提供合法身份或可得时钟时不会自动推断。来源的历史声明由用户/供应商负责，程序保留导入审计。

## 研究与指标

“复权与指标副图”可选日线或分钟。分钟读取当前已落盘的个股分时资料，先在个股分时页更新已授权数据，再按其实际日期选择研究区间；当前分钟副图只支持原始价格。分钟指标按根数计算，MA120表示120根有效分钟，不表示半年线。已知日内缺口后指标重新预热，午休不算缺口，缺分钟不补日线；RSI/MACD预热不足时保持空值。缓存之外的历史分钟不会自动伪造，分钟日期、样本及来源单独报告。

专业图表包括价格均线、MACD、RSI、ATR，各曲线可切换；全历史预热后截取展示窗口。多股比较按共同日期和共同起点100计算，同币种数据才能比较。同行财务显示公告日、报告期和估值日期，缺值不以0填补；历史公告日过滤不等于已具备经供应商认证的历史修订数据库。

“同期相对强弱”也接受已导入的指数。例如先补齐上证指数日线，再比较 `CN.SH:600519` 与 `CN.SH:000001`。指数点位通常没有个股复权因子，选原始价格比较；未经提供完整因子，不会静默给指数伪造复权序列。跨除权区间应同时核对个股原价收益限制。

在研究分类保存命名规则、研究池、标签、模板和参数；名称已有版本时先从列表载入。旧内容可载入后另存新版本，冲突不会覆盖已存在记录。规则先筛选完整可用截面，再限制结果显示；查看覆盖与排除原因，不能把缺财务资料的排除结果解释为不合格公司。

估值情景仅按填写的EPS、增长、倍数、年数和折现率计算敏感性；假设随导出保留。公告事件轴只呈现截止日之前的已缓存公告。

## 本地预警

建立规则、启用并保存。后台每5秒评估本地数据；价格/量能使用不超过120秒的有效报价。持续满足同一条件不会每次重复提醒，条件恢复后再触发仍遵守冷却时间；陈旧报价不冒充实时也不重置条件边沿。公告按日期、标题/链接和规则版本去重。待阅数量、事件证据及确认状态落盘。程序关闭时不会运行；本版仅站内本地提醒，不发送邮件、短信或交易指令。

## 组合账本

组合导入列：`reference,date,kind,market,symbol,quantity,price,cash,fees,memo`。每个账户固定币种；reference为账户内唯一流水编号。kind为deposit/withdraw/buy/sell/dividend/split。买卖cash填0，现金流水quantity与price填0，split的quantity填新增股数。入出金记录净现金，费用填0；交易费用记fees。卖空、负现金和改变已存在reference内容均被拒绝。

报告按日期及记录顺序重建余额，逐笔对账。错误流水通过“纠正”作废，原始记录永久保留，可恢复；会造成其他流水无效的纠错被拒绝。估值只用截止日前最后有效收盘价，显示实际报价日期；持仓缺价时净值与未实现收益为未知。

日级现金流按当日开始发生处理，单位净值用于时间加权收益与回撤；持仓贡献按成本损益，行业集中度按持仓市值。多个币种分别出报告，不直接求和。日期内的实际先后顺序影响资金可用性，导入时须按真实顺序整理。

## 回测与重放

回测为单证券快/慢均线研究：前一日收盘形成信号、下一开盘加滑点执行。必须提供覆盖整个自然日期区间的正式日历、每个开市日已核验约束及必要日线/公司行为。源不齐时保存阻止原因，不返回伪造收益。

默认严格时点模式仅支持沪深京。它使用次日09:25之前可得的首个日线版本，持续冻结这一历史版本，后续更正不回填先前策略的历史；周末等延迟发布资料也按该保守截止检查。日历、约束需在当天09:25前可得，因子需在其日线次日09:25前可得，公司行为需在除权日前可得；上市状态需在决策时已知且覆盖当天。跨退市区间缺乏实际清算数据则阻止，不假设股票始终可交易。可在退市之前的合法区间研究已退市证券。

关闭严格模式可使用当前本地历史进行研究模拟，结果明确标记未验证当时可得性。两种模式都不是全市场动态股票池回测；未提供策略优化器、券商撮合或真实逐笔执行模型。费用、税费和滑点为用户场景参数，不自动推断历史税制。

结果包括成交、跳过原因、现金、持仓、应收分红、基准、回撤、换手和成本敏感性。填写样本外开始日期后，样本外区间以独立初始现金计算，不自动调参。输入快照和参数随运行保存；从历史查看、导出，或输入运行编号后台重放。重放只读冻结输入，后续行情修订不改变旧结果。

## 备份与升级

设置 → 存储与诊断创建 SQLite 一致性快照，配置文件另行保存。schema 10增加专业资料、定义、预警、组合与策略表，不删除旧数据。上线前关闭旧程序，保留可执行文件、配置和数据库备份；回退到旧程序时同时恢复旧数据库，禁止旧程序直接打开新schema。

发布验收使用隔离数据库与模拟数据；真实交易时段的持续采集还取决于 Tushare 权限、网络和供应商返回。不能从非交易日的测试宣称已验证真实盘中连续运行。

## AI 个股分析（0.5.0）

设置 → AI 模型配置兼容接口、模型 ID 和 API Key。个股 → AI 分析选择研究方式，点击生成。模型在后台解读本地公开市场数据，报告与输入依据自动落盘；个人备注折叠保留且不进入模型请求。数据变化后按需更新，相同输入复用，不随页面轮询重复调用。详细配置、报告边界和 API 见 [0.5.0说明](RELEASE_0.5.0.md)。schema 11新增AI报告表，回退时同时恢复旧数据库。
