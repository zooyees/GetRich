# 0.3.0 · 个人研究工作台基础版

系统性方案与后续验收标准见 [建设方案](PROFESSIONAL_WORKSTATION_PLAN_2026-11-01.md)。本版完成本地分析、条件选股、研究记录、证据快照与数据库备份的可用闭环；复权、多源核对、指标副图、组合与可信回测按方案继续建设，尚未宣称完成。

- 桌面和浏览器在“行情 → 个股详情”新增“研究分析”。指标包含收益、MA、RSI、MACD、ATR、波动、最大回撤和相对20根均量，由同一 Rust 核心计算；显示日期、样本、来源与公式，缺失显示 —。
- 本地条件选股支持沪深京 A 股或自选，配置最低涨幅及成交额，同日同币种比较，排除未来报价并报告覆盖范围，候选可继续打开研究。
- 四段研究笔记按股票保存，每次保存追加版本并固定分析证据。旧版本写入冲突会被拦截，未保存草稿按股票保留在当前会话，后台刷新不会覆盖正在编辑的内容。
- 可查看最近100个历史版本。保存时的指标和来源随记录保留，后续历史修订不改写旧证据。
- 设置页新增后台数据库一致性备份，完成路径见数据中心任务结果；包含行情与研究记录，不含配置文件。

本版仍使用原始价格，未复权；跨除权收益和波动可能失真，页面持续提示。数据源授权与实时成功状态仍须核对。指标不是自动买卖结论。

数据库升级至 schema 8。升级前备份旧数据库和配置，关闭旧程序后替换运行文件。降级应恢复旧版本备份。本轮开发使用隔离数据库，未迁移用户正在运行的数据库或覆盖根目录程序。
