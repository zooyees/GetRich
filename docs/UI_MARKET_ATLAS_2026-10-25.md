# GetRich 界面评估与大盘星图落地

日期：2026-10-25。范围：Windows 原生桌面与内置 Web 的行情、个股详情、市场态势、数据中心、设置。

## 评估与调整

| 页面 / 问题 | 已落实的调整 |
| --- | --- |
| 全局导航、密度与视觉层级不统一 | 统一品牌导航、标题层级、边距、卡片、表单、边框、选中态和语义颜色；新配置默认深色，保留显式浅色及系统主题偏好。 |
| 行情页筛选、列表与详情相互抢占空间 | 分开工作区标题、市场切换、筛选、表格、分页；桌面列表宽度可调；Web 大屏双栏、窄屏列表与详情切换。 |
| 详情页价格摘要被大图挤到屏幕外 | 报价日期、价格与常用指标置于图表之前；限制图表高度；周期、缩放平移、原始价格说明和资料区各自分区。 |
| 市场态势缺少全局空间表达 | 主视图改为行业分组矩形树图，采用共享的 squarified 布局；来源行业、个股面积、涨跌颜色和数据范围分开表达。旧市场解读作为辅助信息保留。 |
| 数据页与设置页单列堆叠、横向空间浪费 | 宽窗口使用两列卡片，窄窗口退为单列；导入、同步、任务、数据源、外观、自选、存储诊断拆成独立区域。 |
| 刷新、空数据与异常交互不明确 | 星图提供读取状态、空态、错误与重试；更新失败标明保留旧截面；异步返回检查页面和请求代次，避免跳页或旧查询覆盖新查询。 |
| 可用性和性能 | Canvas / egui 绘制大量矩形，小块隐藏文字，缩放后显示；键盘选股、搜索定位与文字详情提供替代入口。搜索和自选高亮不改变面积分母。 |

## 星图功能

- 范围：沪深京 A 股、沪市、深市、北证、科创板、创业板、港股、美股；各范围独立计算币种，不直接相加人民币、港元和美元。
- 面积：自动、流通市值、总市值、成交额、等面积。自动模式在至少 90% 同日有效样本有流通市值时使用市值，否则在成交额覆盖足够时使用成交额，否则等面积。页面始终写明实际面积指标。
- 交互：搜索名称 / 代码 / 行业、高亮自选、仅看当前市场自选、行业下钻和返回、滚轮缩放、拖动平移、重置、点击速览和双击个股详情。Web 支持浏览器全屏；桌面支持专注视图。
- 图例：涨跌幅在 ±5% 饱和；支持红涨绿跌与绿涨红跌。缺失涨跌幅使用单独灰色，平盘和未知分别计数。
- 信息：来源交易日、计算时间、数据版本、同日报价数、展示数、无报价、其他日期、无效 / 币种不符、权重缺失、延迟与未分类。行业标题显示有效展示成分的等权涨跌均值。
- 指数：按代码固定卡位；缺失数据保留空位。指数和股票报价在同一数据库读事务内读取，分别标注各自交易日；指数不会混入股票面积和涨跌家数。

## 数据准确性约束

只有在市股票、同一来源交易日、有效价格和匹配币种参加星图。旧日期、未来报价和异常数值有单独计数。数据版本、元数据与报价在同一 SQLite 读事务内获取。

市值必须具有与报价相同的 `as_of` 日期；缺少同日市值的股票不以成交额冒充市值。选择等面积可查看缺少权重的有效报价。行业沿用数据源的 `industry`，未接入申万二级行业或指数成分数据时不提供相应伪筛选项。覆盖率仅指已导入的本地样本，不宣称全市场完整覆盖。

新增后台任务 `tushare.valuations` 和 `tushare.indices`，在两端数据中心分别执行。`daily_basic` 的市值单位按万元乘 10000 转为元，并保留日期和来源；该接口为收盘后更新，不能标为实时流通市值。单位和发布时间依据 [Tushare 每日指标](https://tushare.pro/document/2?doc_id=32)。

`index_daily` 的成交量、成交额按来源单位转换，卡片标明日线日期。指数成交额不作为整个股票市场的成交总额，相关口径区别见 [Tushare 指数日线](https://tushare.pro/document/1?doc_id=95)。

真实账号权限、盘中源延迟与行情逐条一致性尚未以交易所或东方财富逐笔对账验证，因此不声称准确性已经超过东方财富。当前交付提高的是口径一致性、缺失可见性和来源可追溯性。

## API 与扩展

`GET /v2/market-map?board=CN&metric=auto&industry=&watch_only=false&aspect=1.6`，或 invoke `market.map`。响应带 `schema_version=1`、查询、交易日、币种、指标、覆盖统计、数据版本、分组、矩形坐标、报价及权重来源。行业坐标相对整个视图归一化；个股坐标相对行业内容区归一化，客户端预留行业标题。

文件导入的市值示例（基础货币单位，不是万元）：

```json
{
  "listings": [{
    "symbol": "600001",
    "market": "CN.SH",
    "industry": "示例行业",
    "metadata": [{
      "key": "float_market_cap",
      "value": "200000000",
      "source": "your-provider",
      "as_of": "2026-10-23"
    }]
  }]
}
```

旧日期的元数据不会覆盖较新日期；无日期的新值会清除旧日期，防止继承日期后冒充同日权重。

## 验证边界

自动测试覆盖 6001 个矩形的面积、边界、不重叠、极端数值；同日 / 跨市场过滤、缺失权重、未知涨跌、固定指数卡位、市值换算及元数据日期；Web 的请求竞态、绘制、搜索、自选高亮、键盘、选股和缩放；原生四类工作区在 760×600、1024×768、1440×900、1920×1080 的主要操作布局。
