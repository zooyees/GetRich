# 0.4.1 · 个股页面布局与字体优化

本版统一个股行情、分时、F10、资金、公告，以及短线/波段/长线研究分析的排版。桌面和浏览器同步调整。

- 字体：桌面优先使用Segoe UI及微软雅黑中文回退，数字使用Consolas；个股正文14、标签/来源12、操作13、分区标题16—17、指标数值16。混合中文的OHLC使用正文族，避免不协调的等宽中英排版；图表坐标提高可读性。
- 页头与导航：名称、价格和报价信息保持紧凑；子页面导航独立于K线周期/缩放，防止同排十余项控件挤压。浏览器刷新入口并入导航行，其他子页面收起空图表工具栏。
- F10：宽屏按估值/财务、公司/股东分两栏；窄屏单列。统一指标尺寸，公司资料使用固定标签列，主营/介绍可展开；股东数量和比例右对齐，长名称保留悬浮全文。
- 资金：摘要和历史表分层，数字列固定对齐；涨跌色用于净流向，买入/卖出总额使用中性色。统计说明折叠，保留完整分项。
- 公告：日期列固定，长标题在独立内容列内换行；日期显示统一为YYYY-MM-DD；元信息和正文分层。
- 研究分析：分析概览、研究记录、条件选股分区；普通口径提示折叠，来源和异常继续显示。笔记输入增加内边距、统一行距，窄屏操作行可换行，保存和冲突保护沿用已有流程。

工程上新增个股专用样式模块和浏览器样式文件，避免把仪表盘的大卡片/大字号直接应用于资料页。数据库schema为10，沿用现有配置、行情和研究记录。操作手册仍适用于本版。
