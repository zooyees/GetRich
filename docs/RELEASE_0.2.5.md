# GetRich 0.2.5 · 个股详情布局与星图加载修正

- 报价指标使用统一等宽网格，标签、数值及间距对齐；宽详情区一行八项，窄区域分为两行。长数值和行业名称保留悬停全文。
- 行情、F10、资金及公告使用统一尺寸标签。周期、平移、缩放、回到最新及历史更新集中在工具栏，窄屏自动分行。历史范围与均线图例压缩为辅助信息行，来源及更新时间保留在提示中，减少图表上方留白。
- 星图更改市场、行业、面积或日期策略时保留上一幅有效画面；旧响应结束后自动读取最新条件，过期响应不会覆盖当前筛选。读取失败保留旧图并显示重试提示。
- Web 同条件刷新复用进行中的读取，避免慢请求被定时刷新反复取消而持续加载；切换条件仍取消旧请求，离开页面后忽略旧响应。
- 修正桌面操作队列满时仍递增请求版本，导致有效响应被丢弃的问题。加载过程中持续驱动界面更新。

验证：126 项 Rust 测试、26 项 Web 回归、严格 Clippy 与格式检查通过。布局检查覆盖深浅主题及 760×600、1024×768、1440×900、1920×1080，检查指标等宽、标签基线和工具栏边界；另以真实 Windows 窗口核对个股详情与全市场星图。

继续使用 schema 6，无新增数据库迁移。测试使用独立数据库与本地模拟数据源；不会修改正式行情数据或调用真实账号接口。升级前关闭旧程序，备份后将原有配置与数据库复制到新版目录。
