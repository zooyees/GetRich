# GetRich 0.2.7 · K 线工具栏、日均线与缩放修正

- 历史日期范围、根数、价格口径及所选 K 线的开高低收移入顶部工具栏；宽屏位于周期与操作按钮之间，窄屏在同一工具栏内分行。均线勾选与数值使用等宽网格，保持右侧各区域边界一致。
- 增加 MA30、MA120 半年线、MA250 年线，与 MA5、MA10、MA20 一起提供独立 checkbox。数值跟随十字光标所选日期，离开图表显示当前视窗最后一根。显示开关保存在本地设置，可跨股票、刷新和重启保持；全部关闭有效。
- 六条均线均按交易日日线收盘价的简单平均计算，盘中日 K 使用其动态最新价。周/月 K 按对应周期最后一个已导入日线观察值对齐，不能误作 120 周或 250 月。日线不足相应周期时显示 —，不填充不完整均值。
- 后端在完整已载入日线（上限 20,000 根）上计算均线，再映射到返回的展示周期；即使 API 仅请求一根或限定较晚的起始日期，也保留之前日线预热。无可用日线时不伪造日均线；不需要额外数据源权限。
- 修正放大到少于 80／40 根时固定槽位和柱宽上限导致的蜡烛不再变宽、左侧数据不断消失。可见根数、槽距、蜡烛宽度及鼠标命中统一计算；缩放可到一根，关闭的均线不参与纵轴范围。
- 验证包括均线手算、跨周期对齐、有限窗口预热、全部关闭和配置校验、连续放大、隐藏均线不影响纵轴以及两端布局回归。
- 133 项常规 Rust 测试、32 项 Web 回归通过；使用独立数据库检查 Windows 窗口中的工具栏、六条均线数值和勾选操作。缩放到一根后，滚轮及缩放手势仍能正常缩回。

继续使用 schema 6，无新增数据库迁移。升级前关闭旧程序，保留原有配置与数据库。
