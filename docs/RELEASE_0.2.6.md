# GetRich 0.2.6 · 行情布局与实时刷新调度

- 修正全市场列表分页被表格挤出窗口的问题；窄侧栏使用紧凑页码并保留完整范围提示。
- 行情列表固定使用窗口宽度的 20%，窄窗口仍采用列表／详情单页布局。表格列按剩余宽度分配，长数值可悬停查看；市场切换改为下拉框。
- 股票名称、代码、价格及涨跌组成紧凑信息组，自选操作独立靠右；报价指标和图表工具保持统一对齐。旧配置中的绝对列表宽度不再覆盖当前比例布局。
- 实时行情最多并发三个批次，沿用账号与接口共享配额。所有批次成功且通过日期检查后才将整轮提交入库；任何批次失败保留上一轮有效报价。
- 刷新间隔按轮次起点计算，包含网络和入库耗时；慢轮次不会重叠或补发追赶请求。只有确认交易日历后才标记处于采集时段。
- 浏览器星图把指针移动、拖动及滚轮缩放合并到显示帧，减少重复全量绘制；离开页面会取消待绘制任务。刷新失败保留旧图并支持恢复。
- 验证：129 项常规 Rust 测试、额外 6,000 股热更新压力检查、28 项 Web 回归及严格静态检查；独立测试库核对真实 Windows 窗口布局。5,572 股的 120 个指针事件从 74 次绘制降为 1 次，事件处理从约 2.8 秒降为 104 毫秒。

验证与性能数据见仓库中的 `docs/MARKET_REFRESH_AUDIT_2026-10-25.md`。2026-10-25 为非交易日，未调用真实账号实时接口；本次通过本地模拟交易数据、并发热更新及浏览器连续刷新验证，交易日真实数据源与桌面 GPU 帧率仍需实盘核验。
