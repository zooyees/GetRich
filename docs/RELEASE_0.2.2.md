# GetRich 0.2.2 · 星图、历史行情与个股研究

## 界面与星图

- 移除应用导航左侧的 G / GetRich 品牌块，保留原生窗口标题与应用图标。
- 星图改为全宽主画布；市场与面积指标、搜索和刷新集中在紧凑工具栏。指数使用单行摘要。筛选和个股速览默认收起，按需悬浮打开，不再挤占画布。
- 常用桌面尺寸下，画布至少占导航下工作区面积的 75%；760×600 小窗口至少 60%。保留缩放、平移、行业下钻、搜索、自选高亮和双击个股详情。
- “刷新行情”现在提交后台采集任务，获取列表与有效行情后，按行情日期补充市值和指数。只有连接测试成功、没有实际报价时，不再显示刷新成功。市值或指数权限失败仍保留有效行情，结果列明各项原因。
- 空库且已配置 A 股数据源时，自动发起一次初始化同步。周期性读取与筛选只读取本地数据，避免重复提交采集任务。
- 股票列表与日线采集支持分页；最近交易日尚未发布日线时，回退到已实际发布数据的交易日。

## 个股行情与资料

- 打开 A 股详情时自动检查历史缓存，后台从上市日期补全日线，完成后自动刷新图表。即使快照已包含一根日线，也会补全。手动“更新完整历史”始终可见，已有行情在刷新时继续展示。
- 历史查询和周/月合成上限扩展到 20,000 根日线，图表可平移查看早期记录，不再受原 800 根显示请求或 5,000 根读取上限截断。价格仍为原始价格、未复权，界面明确说明。
- 增加分时视图：当日使用 `rt_min_daily`，已结束交易日使用 `stk_mins`。按真实分钟绘制成交价、成交量加权均价、分钟成交量、昨收百分比参考与悬停读数。过滤非交易时段、错误日期与无效行，保留缺失分钟断点。
- 新增 F10：公司概况与主营业务、财务指标、估值股本、最新报告期前十大股东。财务报告期、公告日期、数据日期和获取时间分别展示。
- 新增资金页：最近 60 个交易日资金流向，大单与超大单净额，以及近 5 / 20 日净流入。金额统一为元。供应商净流入与分类差额分别标注，不混用口径。
- 新增公告页：近一年公告的日期、标题和原文链接；对外链接仅允许 HTTP(S)。权限不足时明确显示接口返回原因，可手动重试，也可进入巨潮资讯官方公告查询。
- 桌面与 Web 共用 `stock.research` 缓存接口及 `stock.research` 后台任务，分区为 `history / intraday / f10 / funds / announcements`。失败保留上次成功数据；行情、财务、资金、公告分区独立加载。
- 修正多实例共用数据库时，一实例完成市场重算、另一实例仍读取旧内存快照的问题。读取校验持久化版本，快照发布不可回退。

## 验收与升级

114 项 Rust 测试、18 项 Web 模块回归、严格 Clippy、格式检查及 8 个独立进程 API 场景通过。Windows 实际窗口检查与 headless 布局检查分开执行；布局检查覆盖深浅主题、四种窗口尺寸与新增资料分区。

发布使用独立目录 `GetRich-Windows-0.2.2-20261025`，压缩包不包含用户配置、Token 或测试数据库。升级前关闭旧程序，备份旧目录的 `config.json` 和数据库，再复制到新版本目录并启动。数据库会自动升级到 schema 6；如需回退旧版，请使用升级前备份。不要让不同数据库版本的程序同时访问同一个升级后数据库。
