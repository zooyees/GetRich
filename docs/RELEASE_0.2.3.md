# GetRich 0.2.3 · 星图底栏、详情跳转与自选搜索

- 星图同步进度、同步结果及查看结果入口移到底边栏右侧第一行，报价日期、覆盖数量、面积口径移到右侧第二行。色阶和涨跌家数保留在底栏左侧，画布上方不再保留这两行状态信息。窄窗口文字可截断并悬停查看完整内容，不侵占画布。
- 修正星图速览打开详情后被列表后台刷新覆盖的问题。通过速览、双击、Enter 或近期记录打开股票时，保留指定市场和代码，即使该股票不在当前自选或筛选结果内。用户主动选另一只股票、切换市场或修改筛选时恢复列表选择。打开详情会关闭星图悬浮窗并切回行情走势。
- 自选管理新增本地标的搜索，支持中文名称、代码、英文名称和市场筛选。选择结果自动填写代码、交易市场和显示名称；支持上下键选择、Enter 填入和已自选标记。保留手动输入，未匹配时说明同步股票列表或更换搜索条件。
- 搜索使用后台读取、输入防抖及响应校验，快速更改关键词或市场时，旧结果不会覆盖新结果。桌面与浏览器端同步修正。

验证包括 116 项 Rust 测试、21 项 Web 回归、严格 Clippy、格式与发布包检查。新增回归覆盖列表外股票跳转、空筛选下保持目标、按名称/代码搜索和正确填入交易市场、旧搜索响应隔离、底栏位置及多尺寸深浅主题布局。实际 Windows 窗口已验证：5572 只股票的星图底栏布局；从星图打开不在当前自选列表内的工商银行，并在后台刷新后保留正确详情；按代码查找招商银行、自动填入字段并保存自选。测试使用独立配置和数据库。

本版本继续使用 schema 6，没有新增数据库迁移。发布使用独立目录 `GetRich-Windows-0.2.3-20261025`。升级时关闭旧程序，备份并复制原有 `config.json` 与数据库到新目录；压缩包不包含用户配置、凭据或测试数据库。0.2.2 的历史、分时与资料功能保持可用，公告仍受现有账号的接口权限约束。
