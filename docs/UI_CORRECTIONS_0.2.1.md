# GetRich 0.2.1 桌面 UI 修正

本次根据用户提供的设置、数据中心与行情空库截图调整 Windows 桌面界面。

## 布局与视觉

- 管理页面采用居中限宽工作区，设置最大宽度 1160，数据中心 1240；外边距 28、卡片内边距 24。行情与星图保留可利用全屏面积的研究视图。
- 设置改为左侧四个分类、右侧单一表单。窄窗口改为顶部分类；不再把不同高度的内容拼成四张大卡片。
- 输入框约 38 高，主要按钮约 36 高；主题、配色、默认板块及排序操作显示中文。字段标签、说明、标题分别使用统一层级。
- 数据中心统计卡等宽，导入与同步卡片按实际内容取相同高度；有预览时也保持对齐。
- 行情空库提供完整导入与连接引导；筛选无结果、自选为空、未选股均有对应状态。行情表格固定列宽、数字右对齐、整行高亮。
- 星图指数卡采用纵向内容布局；调整滑块底轨、选择与悬停对比度，修正浅色主题标题颜色。
- 操作反馈改为 6 秒短时提示，避免把“设置已保存”持续显示在数据中心。

## 验收

使用独立配置、端口和数据库运行实际 Windows 测试窗口，检查空库引导、四个设置分类、数据中心、导入预览与后台任务、行情列表及个股 K 线、大盘星图。演示数据导入后明确显示历史日期与来源。检查普通窗口及当前显示器最大化状态。

自动布局回归覆盖深色与浅色两种主题、760×600、1024×768、1440×900、1920×1080 四种逻辑窗口尺寸，以及四个设置分类、数据中心、导入预览、行情详情、空库与星图。额外断言两张操作卡的上下边界一致、卡片不重复累加高度、行情名称列位置及主要操作不超出窗口。

窗口截图验收与 headless 布局回归分别进行，后者不能替代视觉检查。本次未验证多显示器切换、完整辅助功能或真实行情账号权限。

本地检查：106 项 Rust 测试、14 项 Web 模块回归、严格 Clippy 与格式检查通过。0.2.1 发布 CLI 的 8 个进程级场景通过，包含 6001 个标的分页无重复遗漏、星图完整性、导入预览不落库、任务结果与多进程配置合并。

## 安装

使用独立版本目录 `GetRich-Windows-0.2.1-20261025`，避免覆盖正在使用的 0.2.0 目录。压缩包不含测试数据库、用户配置和凭据。需要迁移时，关闭旧程序，备份并复制原目录的 `config.json` 和数据库到新版本目录。
