# 个股页面排版审查 · 0.4.1

| 问题 | 调整 |
| --- | --- |
| 正文、标签、图表、按钮混用10—26px字号；中文细弱，中文与数字字体不协调 | 统一字体回退与字号层级；小号元信息12、正文14、数值16，保留名称/价格的视觉重点 |
| 导航、周期、缩放、刷新挤在同一排 | 导航与图表操作分层；非图表页收起空工具栏 |
| F10连续大卡片、指标过大、公司标签起点不一 | 宽屏两栏、窄屏单列；统一指标网格与公司字段两列 |
| 股东与资金数字列不齐，总买卖金额全部着涨跌色 | 固定列宽、数字右对齐；净额使用方向色，总额保持中性 |
| 公告日期与长标题混排、换行后起点混乱 | 独立日期列与标题列，标题自动换行，统一日期格式 |
| 研究分析提示、指标、笔记、选股连续堆叠 | 划分概览/记录/选股，口径提示折叠，编辑与保存状态保持可见 |

原生端采用`detail_design.rs`统一控件与内容样式；F10、资金、公告使用相同分区组件。浏览器采用独立`stock-detail.css`，限定在个股区域，按容器宽度切换列数。

验收使用隔离数据，覆盖长公司地址、长股东名、长公告标题、多行介绍、正负资金和缺值。检查760/1024/1440/1920宽度及深浅主题下的实际页面；结合原生布局与草稿交互回归。最终发布验证结果见本次交付记录。
